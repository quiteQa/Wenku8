# 文库 · 档案书架 iOS 预览（0.3）

保留原作者的设计思路：档案式排版、编号、细线、奶白纸张、立体抽取书架，以及「发现 / 书架 / 本地 / 我的」四个入口。Apple 风格用于 Cupertino 控件、浮动玻璃导航、弹簧吸附、轻量点按反馈、共享封面过渡与手势返回。

`lib/archive_shelf_geometry.dart` 直接使用原作几何参数。`lib/archive_shelf_preview.dart` 改编原作 `archive_wave.dart` 的渲染对象，保留抽取投影、连续波形、遮挡顺序、书顶阴影和精确点击判定；演示数据和滚动适配独立提供。沿用根目录 LICENSE / NOTICE 中适用的许可与归属。

预览支持四种书库浏览方式：立体书架 + 列表、立体书架 + 宫格、纯列表、纯宫格。还可体验搜索、书架筛选、详情、目录、章节切换、字号与纸色、深色外观和减少动态效果。书架横滑会持续抽取中心档案并吸附；点非中心书脊先居中，再点中心书籍打开详情。底部导航支持拖动预览，松手切换页面。

全部书籍、封面与正文为原创演示内容，四本书共用三章示例正文。数据只在本次运行内保留；本地入口只展示演示书籍，没有实际导入。没有在线书库、账号、同步、听书和桌面小组件。预览不包含原作依赖原生插件的完整液态玻璃折射与纸张弯曲 Hero 飞行，使用系统模糊与 Cupertino 过渡演示对应交互。

## 构建

GitHub Actions **Build iOS UI preview** 在 `codex/ios-preview` 分支推送预览代码时，使用 macos-15 和 Flutter 3.41.5 分析、编译并打包真机 Release IPA。

成功后，从该次运行的 Artifacts 下载 `Wenku8-Preview-unsigned`，解压取得 IPA、SHA256 校验值和安装说明。需要用自己的 Apple 身份签名后安装；不是 App Store 或 TestFlight 包。预览 Bundle ID 独立，不覆盖原应用。

Mac 本地构建需要 Xcode、Flutter 3.41.5、CocoaPods 和网络：

```sh
bash preview/tool/build_ios.sh
```

脚本在临时目录生成 iOS 宿主，不编译根工程缺失模块；结果位于 `preview/dist/`。未签名 IPA 打包后会核验 ARM64 真机平台和 ZIP 完整性。


## 0.3 参考图实现

保留档案书架原有几何与抽取交互，按用户给出的玻璃材质参考调整：棱彩浅底、淡网格、双层高光边缘的玻璃工具栏、当前书籍信息卡与页码胶囊、四栏浮动导航和独立搜索按钮。默认使用纯立体书架展示，列表和宫格仍可从视图按钮切换。分类、题材筛选与搜索会实际改变演示数据集合与数量；数量不使用参考图中的虚构值。

玻璃由有界背景模糊、透明色膜及静态反射边缘组成，不声称等同于系统私有 Liquid Glass 渲染器。原有品牌图标复用自仓库。构建同时执行交互测试并生成 iPhone 模拟器截图，便于核对布局；用户交付文件仍为单独的未签名 IPA。
